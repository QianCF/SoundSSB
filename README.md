# SoundSSB · 浏览器里的上边带声学无线电
> 用声波模拟单边带（USB）调制，在普通电脑声卡的 15–23 kHz 高频段上实现实时语音通信和音频广播。
**不需要任何硬件，不需要无线电执照，打开浏览器就能玩。**

## 这是什么？
这是一个**纯前端实现的软件定义声学调制解调器**。它利用 Web Audio API 和 AudioWorklet，将普通麦克风输入的语音信号通过**单边带（USB）调制**搬移到 15–23 kHz 的超声波频段，再通过扬声器发射出去；接收端则反向搬移回可听频段。
---
## 特性
| 功能 | 说明 |
|------|------|
| 🎙️ **实时对讲** | 按住 PTT 按钮，说话，另一台电脑（同房间）能听到 |
| 📻 **音频广播** | 载入任意音频文件，自动“发射”到高频信道 |
| 🔧 **8 kHz 带宽** | 等效 16 kHz 采样率|
| 📡 **USB 调制** | FFT直接搬移的单边带实现，频谱效率 100% |
| 🎛️ **增益控制** | 麦克风增益、扬声器增益独立调节 |
| 📊 **频谱搬移** | 基于 FFT/IFFT 的频域直接映射，代码极简 |
---
## 工作原理
```
发射链路：
  麦克风 (0–8 kHz) → FFT → 频谱搬移 (+15 kHz) → IFFT → 扬声器 (15–23 kHz)
接收链路：
  麦克风 (15–23 kHz) → FFT → 频谱搬移 (-15 kHz) → IFFT → 扬声器 (0–8 kHz)
```
